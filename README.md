# Akıllı Arıza Talep Yönetimi (FixHub 🎀)

Bu proje, React Native ve Expo altyapısı kullanılarak geliştirilmiş bir Teknik Destek ve Arıza Bildirim Uygulamasıdır.

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları takip edin:

1. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```
